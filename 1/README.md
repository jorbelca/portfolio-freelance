# Demo 1 y 2 — Intake y consulta documental para un despacho

Sistema de automatización para un despacho pequeño: clasifica el correo entrante contra un criterio escrito, registra el motivo de cada decisión y manda a revisión humana lo que no tiene claro. Incluye un chat sobre los documentos del despacho que cita documento y página en cada respuesta, o admite que no tiene información suficiente en lugar de inventar.

Construido con n8n, Postgres/pgvector y modelos vía OpenRouter.
