# Demo 3 — Triage jurídico de incidencias para administradores de fincas

Sistema de automatización para administradores de fincas: clasifica cada incidencia contra un criterio escrito, cita la norma o cláusula estatutaria que aplica, arranca el contador de los plazos que corren y manda al administrador lo que no le corresponde decidir a una máquina.

Construido con n8n, Postgres y modelos vía OpenRouter.
