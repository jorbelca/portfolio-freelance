Operación del workflow

La pausa impide nuevas ejecuciones desde este panel. Una ejecución que ya ha comenzado continúa en n8n.

La búsqueda consulta las fuentes habilitadas, cruza el historial, reserva las lecturas y evalúa cada ficha por tareas. Puedes pausarla entre tareas sin perder resultados.

Búsqueda programada

n8n comprueba cada minuto si toca buscar. Solo inicia si permites nuevas ejecuciones, has confirmado el historial y no hay otra ejecución activa o incierta. Al activar esta opción autorizas el uso periódico del motor y modelo guardados.

El intervalo se cuenta desde cada lanzamiento. Tras una parada se inicia como máximo una búsqueda pendiente. La fecha se guarda en UTC; aquí se muestra en la zona horaria de tu navegador.

      Clientes locales · stdio

      Copia esta configuración en tu cliente MCP. El proceso lee MCP_TOKEN de 11/.env; el secreto no se copia al navegador. La web debe estar arrancada.

      n8n y clientes HTTP

      Usa el endpoint de Streamable HTTP y una credencial Header Auth con Authorization: Bearer seguido de MCP_TOKEN. Guarda esa credencial en el cliente; el ejemplo contiene un marcador.

      Para exponer solo consultas en stdio, añade EMPLEO_MCP_READ_ONLY=1 al entorno del cliente. Cada herramienta documenta entradas, versiones y recuperación de errores.
