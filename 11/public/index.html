      Clientes locales · stdio

      Copia esta configuración en tu cliente MCP. El proceso lee MCP_TOKEN de 11/.env; el secreto no se copia al navegador. La web debe estar arrancada.

      n8n y clientes HTTP

      Usa el endpoint de Streamable HTTP y una credencial Header Auth con Authorization: Bearer seguido de MCP_TOKEN. Guarda esa credencial en el cliente; el ejemplo contiene un marcador.

      Para exponer solo consultas en stdio, añade EMPLEO_MCP_READ_ONLY=1 al entorno del cliente. Cada herramienta documenta entradas, versiones y recuperación de errores.
