      Clientes locales · stdio

      Copia esta configuración en tu cliente MCP. El proceso lee MCP_TOKEN de 11/.env; el secreto no se copia al navegador. La web debe estar arrancada.

      n8n y clientes HTTP

      Usa el endpoint de Streamable HTTP y una credencial Header Auth con Authorization: Bearer seguido de MCP_TOKEN. Guarda esa credencial en el cliente; el ejemplo contiene un marcador.

      Para exponer solo consultas en stdio, añade EMPLEO_MCP_READ_ONLY=1 al entorno del cliente. Cada herramienta documenta entradas, versiones y recuperación de errores.

      Endpoints y herramientas disponibles

      Abre una operación para consultar sus parámetros y lo que devuelve. Este catálogo documenta las operaciones; no las ejecuta.

      MCP devuelve {ok: true, data: …} en el resultado estructurado. En caso de fallo devuelve {ok: false, error: {code, status, message, recovery, retryable}}. La API HTTP devuelve directamente los datos o {error: "…"}; un proceso fusionado puede incluir target_id.

      Los parámetros entre llaves van en la ruta. En GET, los demás van en la consulta; en POST, PUT y PATCH van en el cuerpo JSON. Las entradas mostradas son las de MCP: las diferencias con HTTP se indican en cada respuesta. Los parámetros de ruta se omiten del cuerpo HTTP. Las escrituras requieren la credencial del cliente; las rutas internas de n8n usan N8N_TOKEN.
